# bayan

Поиск файлов с одинаковым содержимым. Используются Boost.Filesystem,
Boost.Program_options, Boost.CRC и MD5 из Boost.UUID. Стандарт C++14.

## Сборка

Для Ubuntu:

```sh
sudo apt-get install cmake g++ libboost-filesystem-dev libboost-program-options-dev python3
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Python нужен только для тестов. Сборка без тестов: `-DBUILD_TESTING=OFF`.
Для проверки количества чтений на Linux дополнительно установите `strace`.

## Параметры

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| `--help`, `-h` | Показать справку | |
| `--scan`, `-d` | Директории для сканирования | Текущая директория |
| `--exclude`, `-e` | Исключённые директории вместе с содержимым | Нет |
| `--depth`, `-l` | Глубина: 0 — без вложенных директорий, 1 — ещё один уровень, -1 — все уровни | 0 |
| `--min-size`, `-m` | Минимальный размер в байтах, включительно | 2, то есть больше 1 байта |
| `--mask`, `-f` | Маски имён: `*` — любая последовательность, `?` — один символ | Все имена |
| `--block-size`, `-s` | Размер блока S в байтах, положительное число | 4096 |
| `--hash`, `-a` | Алгоритм: `crc32` или `md5` | crc32 |

`--scan`, `--exclude` и `--mask` принимают несколько значений и могут повторяться.
Достаточно совпадения хотя бы с одной маской. Регистр букв в масках не учитывается.
Маски заключайте в кавычки, чтобы их не раскрывала оболочка.
Относительные пути считаются от текущей директории. Повторные пути к одному файлу
не создают дубликатов в выводе. Символические ссылки пропускаются.

```sh
./build/bayan --scan ./data ./backup --exclude ./data/cache ./backup/tmp \
  --depth -1 --min-size 2 --mask '*.txt' '*.bin' --block-size 1024 --hash md5
```

Вывод содержит только группы дубликатов: один полный путь на строку,
между группами пустая строка. Если дубликатов нет, вывод пустой.
Ошибки выводятся в stderr, код завершения при ошибке — 1.
Во время поиска файлы не должны изменяться.

## Сравнение

Сначала файлы группируются по размеру без чтения содержимого.
Группы из одного файла дальше не обрабатываются.
У остальных читается один блок и вычисляется его хеш. Группа разделяется по хешам,
и следующий блок читается только у подгрупп, содержащих хотя бы два файла.
Каждый блок каждого файла читается не более одного раза. Буферизация чтения
отключена, чтобы не запрашивать следующие блоки заранее.
Последний блок дополняется нулями до S байт. Если совпали все блоки,
файлы считаются дубликатами. Коллизии хешей игнорируются по условию задания.

## Пакет

На Linux:

```sh
sudo apt-get install dpkg-dev file
cmake --build build --target package
sudo apt-get install ./build/bayan-0.0.1-Linux.deb
bayan --help
```

GitHub Actions собирает и проверяет программу, создаёт DEB-пакет `bayan`,
устанавливает его и публикует в GitHub Releases после push в ветку `boost`.
Bintray закрыт с 1 мая 2021 года, поэтому используется GitHub Releases:
[объявление JFrog](https://jfrog.com/blog/into-the-sunset-bintray-jcenter-gocenter-and-chartcenter/).
